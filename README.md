# MC EMS License Manager

## Plugin Features
- **License Management**: Easily manage licenses for your Minecraft server.
- **User Management**: Control user access and permissions.
- **Advanced Configuration**: Highly configurable settings for tailored usage.

## Installation
1. Download the latest version of MC EMS License Manager from the releases page.
2. Place the downloaded jar file in the `plugins` directory of your Minecraft server.
3. Restart your server or use the `/reload` command.

## Configuration
- Navigate to the plugin's directory in `plugins/MC-EMS-License-Manager`
- Edit the `config.yml` file to set up your preferred settings:
  - **Database Settings**: Configure database connection parameters.
  - **License Options**: Set up license types and durations.

## Usage
- After configuration, use `/license` command to manage licenses.
- Use `/license list` to view all active licenses.
- Command examples:
  - `/license create <user> <duration>` - Creates a new license for a user.
  - `/license revoke <user>` - Revokes a license from a user.

For more detailed information, refer to the official documentation or community forums.
